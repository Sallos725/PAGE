PAGE — Windows 포터블

[실행]
1. 이 폴더의 PAGE.exe 를 더블클릭하세요. 잠시 뒤 브라우저가 열려요 (http://127.0.0.1:8787).
2. 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행" 을 누르세요.
   (서명하지 않은 무료 프로그램이라 뜨는 안내예요.)
3. 검은 창이 PAGE 서버예요. 창을 닫으면 꺼져요.

[쓰는 법]
- 가져오기: RisuAI 에서 채팅을 내보낸 .json 파일을 올리면 서고에 꽂혀요.
- 원본 연결: PocketRisu 를 이 PC 에서 쓰고 있다면 서고 머리의 "원본 연결" 에서
  PocketRisu 폴더(안에 save 폴더가 있는 곳)를 고르세요. PAGE 는 읽기만 해요.
- PDF 내보내기는 Docker 판에서만 돼요. EPUB·JSON 은 여기서도 돼요.

[데이터]
- 서고·책갈피·형광펜·가져온 채팅은 이 폴더의 data 폴더에 있어요. 백업은 data 폴더를 복사하면 돼요.
- 이 폴더를 지우면 데이터도 같이 지워져요.

[업데이트]
- PAGE 를 끄고, 새 zip 의 압축을 풀 때 풀 위치(대상 폴더)를 지금 이 폴더(PAGE.exe 가 있는 곳)로 고르세요.
  Windows 가 처음 제안하는 "PAGE-…-win-x64" 새 폴더가 아니에요. 같은 이름 파일은 덮어쓰기를 고르면 돼요.
- data 폴더는 zip 에 없어서 그대로 남아요.

[포트 바꾸기]
- 8787 을 다른 프로그램이 쓰면, 이 폴더에 page.env 파일을 만들고 PAGE_PORT=8788 처럼 적으세요.
